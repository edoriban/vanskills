## Async vs Sync Endpoints

- Use `async def` ONLY when everything inside is non-blocking (async DB driver, httpx, etc.).
- Blocking code inside `async def` freezes the event loop. In doubt, use plain `def` — FastAPI runs it in a threadpool.
- Same rule applies to dependencies.

```python
@app.get("/items/")
async def read_items(db: DBDep):          # async driver -> async def
    return await db.fetch_items()

@app.get("/reports/")
def build_report():                        # blocking lib -> plain def
    return heavy_blocking_call()
```

## Annotated Everywhere

Always use `Annotated` for params and dependencies. Create type aliases for reusable dependencies.

```python
from typing import Annotated
from fastapi import Depends, Path, Query

@app.get("/items/{item_id}")
async def read_item(
    item_id: Annotated[int, Path(ge=1)],
    q: Annotated[str | None, Query(max_length=50)] = None,
): ...

CurrentUserDep = Annotated[User, Depends(get_current_user)]
```

## Pydantic v2 Models

- No `...` (Ellipsis) defaults — a field without default is already required.
- No `RootModel` — use `Annotated[list[X], Field(...), Body()]` instead.
- Separate `XCreate` / `XUpdate` / `XOut` schemas; never return ORM objects raw.
- Always declare a return type (or `response_model` when internal type differs from public schema). It validates, filters sensitive fields, and serializes fast on the Rust side. Do not use `ORJSONResponse`/`UJSONResponse` (deprecated).

```python
from pydantic import BaseModel, ConfigDict, Field, field_validator

class UserOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)  # ORM mode
    id: int
    email: str

class UserCreate(BaseModel):
    email: str
    password: str = Field(min_length=8)

    @field_validator("email")
    @classmethod
    def normalize(cls, v: str) -> str:
        return v.strip().lower()

@app.post("/users/")
async def create_user(data: UserCreate) -> UserOut: ...
```

## Routers

Declare prefix, tags, and shared dependencies on the `APIRouter` itself, not in `include_router()`. One HTTP operation per function.

```python
router = APIRouter(
    prefix="/items",
    tags=["items"],
    dependencies=[Depends(get_current_user)],
)
app.include_router(router)
```

## Dependency Injection

Use dependencies for shared logic, external resources, auth checks, and cleanup with `yield`. Prefer function dependencies over class dependencies.

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

DBDep = Annotated[Session, Depends(get_db)]
```

## Auth (PyJWT + passlib)

Wire auth as a dependency chain: `OAuth2PasswordBearer` -> decode JWT -> load user. Token rules, hashing params, and secret handling are owned by `skills/api-security-best-practices` — follow that skill; this is only the FastAPI wiring.

```python
from fastapi.security import OAuth2PasswordBearer
import jwt

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="auth/login")

async def get_current_user(token: Annotated[str, Depends(oauth2_scheme)], db: DBDep) -> User:
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=["HS256"])
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="Invalid token")
    user = db.get(User, payload["sub"])
    if user is None:
        raise HTTPException(status_code=401, detail="User not found")
    return user
```

## Rate Limiting (slowapi)

```python
from slowapi import Limiter, _rate_limit_exceeded_handler
from slowapi.errors import RateLimitExceeded
from slowapi.util import get_remote_address

limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter
app.add_exception_handler(RateLimitExceeded, _rate_limit_exceeded_handler)

@app.post("/auth/login")
@limiter.limit("5/minute")          # decorator needs `request: Request` param
async def login(request: Request, ...): ...
```

## Alembic Migrations

- Never edit applied migrations; create a new one.
- Review autogenerated migrations — autogenerate misses renames, server defaults, and some type changes.

```bash
alembic revision --autogenerate -m "add users table"
alembic upgrade head
alembic downgrade -1
alembic history
```

## Testing (pytest + httpx)

Use `httpx.AsyncClient` with `ASGITransport` and `dependency_overrides` for test doubles. Test style, fixtures, and mocking conventions are owned by `skills/pytest`.

```python
import pytest
from httpx import ASGITransport, AsyncClient

@pytest.fixture
async def client():
    app.dependency_overrides[get_db] = get_test_db
    async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as c:
        yield c
    app.dependency_overrides.clear()

@pytest.mark.asyncio
async def test_create_user(client):
    resp = await client.post("/users/", json={"email": "a@b.com", "password": "secret123"})
    assert resp.status_code == 201
```
